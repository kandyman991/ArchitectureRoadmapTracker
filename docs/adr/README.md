# Architecture decision records

When a proposal changes approved canonical model semantics, completion gates, authorization, integration boundaries or tree-first UI contract, add `NNNN-short-name.md` here **before** implementation. Include context, considered alternatives, decision and status (proposed/accepted/superseded), impacted ART requirements, migration/security consequences, and regression gates. A PR plus explicit user approval is required. The index of accepted baseline decisions is [DECISIONS.md](../../DECISIONS.md); do not delete historical ADRs.
